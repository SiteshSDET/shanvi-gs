Saved only in this browser as a reminder. This does not send SMS/calls. Browser alerts go to the phone where you enable them.
How to turn on free order alerts
  1. On the manager phone, open this HTTPS site, sign in, tap Enable browser alerts, and choose Allow.
  2. Keep this Manager page open and signed in. The live Supabase order connection will show a notification for customer orders. Tap Test sound and notification to check your phone's permission and alert.
  3. For iPhone/iPad, add the site to the Home Screen and open it there if Safari requires it for notifications. Browser or operating-system settings may still mute alerts.
  4. Alerts while the page is closed need the additional Web Push setup in SUPABASE_SETUP.md. SMS or phone calls need a separately configured messaging provider; a phone number by itself cannot receive website notifications.
Enter the exact value saved for MANAGER_ENROLLMENT_CODE in Supabase Edge Function Secrets. Push enrollment will fail until the three notification functions are deployed.
