Mobile setup steps
  1. Open this store link on the manager's phone and sign in. Use Chrome on Android. On iPhone/iPad, open in Safari, tap Share → Add to Home Screen, then launch the installed store icon.
  2. Allow notifications when the phone asks. If no prompt appears, enable notifications for this site/app in the phone's Settings.
  3. Enter the manager push code below and tap Enable browser alerts. Wait for the message that push is enabled on this device.
  4. Tap Test sound and notification. New orders can then notify this phone even when the store page is closed, subject to phone notification, Focus/Do Not Disturb, and battery settings.
